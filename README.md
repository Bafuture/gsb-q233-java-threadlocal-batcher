## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的写入走线程本地缓冲攒批，但之前出现过顺序错乱、进程退出丢数据、缓冲无上限把内存吃满。请从零实现一个线程本地缓冲与批量合并组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 每个线程独立缓冲写入，达到批量或超时后刷出到下游；2) 顺序保证：同一线程的写入必须按提交顺序刷出，不同线程的相对顺序不做保证但必须说明；3) 内存上限：缓冲总大小超过阈值时必须触发刷出或拒绝写入，不得无限增长；4) 崩溃安全：刷出动作要能带序号并支持重复刷出幂等，下游按序号去重后结果与只刷一次一致；5) 支持显式 flushAll：调用后必须保证所有线程的缓冲都已刷出（可配置超时），超时后报告未完成线程；6) 支持线程退出时自动刷出，线程池回收线程不得导致数据丢失；7) 提供统计：刷出次数、合并比例、拒绝次数与各线程缓冲深度；8) 测试覆盖顺序保持、批量与超时触发、内存上限、重复刷出幂等、flushAll 超时与统计；`mvn -q verify` 一条命令跑通。
